## Scope boundaries

The repository is the implementation source. Existing unrelated personal Library videos are not product assets. Railway location data is as accurate as its upstream provider; estimates must retain their label. Manually entered journeys and OCR are self-declared membership, not verification by Indian Railways. Production domain, mail delivery, certificates, external provider credentials, infrastructure and an independently observed restore/load test must be configured and verified before a public launch.
